## 什么时候用

用户问课表、上课时间地点、某天有哪几节课时。

数据在**已经挂载的 MCP server（course）**里，工具名都以 `mcp_course_` 开头。不要凭印象编时间地点。

## 步骤

1. 先判断问法：
   - 问「某门课」→ 调 `mcp_course_query_course`，参数 `name` 用课程名关键字（如「机器学习」「统计」）
   - 问「周几/今天/明天」→ 调 `mcp_course_courses_on`，参数 `day` 用「周一」…「周五」；不给 day 就按今天
   - 问「整张课表/都有什么课」→ 调 `mcp_course_list_courses`，无参数
2. 工具返回的是纯文本表格，**原样引用**时间、地点、老师、周次，不要改写格式。
3. 回答里必须带上：星期 + 时间区间 + 地点；有周次限制时补一句（如「7-12 周」）。
4. 如果 MCP 没连上（工具不存在），直接说「课表 MCP 没连上」，不要猜。

## 不要做什么

- 不要用 bash 去读文件猜课表 —— 数据不在工作区里。
- 不要一次把三个工具都调一遍，按问法选一个。
- 不要把「今天」算错：今天是哪天以工具默认行为为准（不传 day 就是今天）。

## 怎么算做完了

- 至少有一次真实的 `mcp_course_*` 调用，并且
- 回答里的时间/地点/周次与工具返回逐字一致。
