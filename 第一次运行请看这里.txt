====================================================
 Mini Cursor —— 第一次运行请看这里（不用改任何代码）
====================================================

这是一个本地桌面 AI 编程智能体（Windows 10/11，64 位）。
自带 Python 运行时，机器上不需要装 Python。

----------------------------------------------------
 一、怎么打开
----------------------------------------------------
 解压版：解压后双击 MiniCursor.exe
 安装版：双击 Setup.exe → 一直点「下一步」→ 装完会自动打开
         （安装版会在桌面创建 MiniCursor 快捷方式）

----------------------------------------------------
 二、没有 API Key 怎么办（推荐先这样看）
----------------------------------------------------
 1. 点右上角「设置」
 2. 勾选「演示模式」（demo mode）
 3. 点「保存」
 4. 在输入框里发下面任意一条，就能看到完整链路：

    · 让 mean 和 median 对空列表抛 ValueError，然后跑测试验证
    · 新建一个 hello.py，打印九九乘法表

 「演示模式」下模型回复是离线回放的固定脚本，
 但 read / write / edit / bash 四个工具、路径越界拒绝、
 bash 超时、写操作确认（diff 预览）全部是真实执行的。

----------------------------------------------------
 三、想用真模型
----------------------------------------------------
 设置里取消勾选「演示模式」，填入自己的 Key（默认支持 DeepSeek）：
   base_url：https://api.deepseek.com/v1
   model  ：deepseek-chat
 保存后即可对话。Key 只存在本机
   C:\Users\<你的用户名>\.desktop-agent\settings.json
 不会上传、不会写进代码、前端也看不到明文。

----------------------------------------------------
 四、能看到什么（对评分点）
----------------------------------------------------
 · 左下角「MCP」面板：两个 server（demo 3 工具 + course 3 工具），
   发「用 MCP 查一下周五有什么课」可看到紫色 MCP 标签的调用卡片
 · 右上角显示步数；写操作会先弹出 diff 确认卡片（点「执行」才落盘）
 · 输入框右侧「停止」可中断任务
 · 工作区默认在 C:\Users\<你的用户名>\.desktop-agent\workspace
   （里面有 stats.py，故意留了一个空列表 bug，可以现场演示「失败→恢复」）

----------------------------------------------------
 五、出问题
----------------------------------------------------
 · 窗口一闪就消失：先确认没有别的 MiniCursor 进程还在跑
   （任务管理器里结束 MiniCursor.exe 后重开）
 · 端口 8765 被占用：程序会自动往后找 8766 / 8767
 · 详细说明见 README.md / docs/build.md
